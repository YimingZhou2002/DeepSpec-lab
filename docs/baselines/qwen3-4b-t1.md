## 逐位置接受率（accept_rate@k）

三个模型的衰减曲线（@0 → @6）：

| dataset | Eagle3 | DFlash | DSpark |
|---|---|---|---|
| gsm8k | 0.859 → 0.391 | 0.914 → 0.402 | **0.933 → 0.550** |
| math500 | 0.813 → 0.300 | 0.887 → 0.315 | **0.914 → 0.479** |
| mt-bench | 0.551 → 0.054 | 0.749 → 0.067 | **0.772 → 0.139** |
| arena-hard-v2 | 0.536 → 0.070 | 0.649 → 0.068 | **0.668 → 0.134** |

DSpark 的衰减最缓 —— 对应 Markov head 补块内依赖；DFlash 在 @0 就明显高于 Eagle3（并行 draft 首位置质量高），但尾端与 Eagle3 接近（纯并行缺少块内依赖）。
